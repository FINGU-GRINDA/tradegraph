# TradeGraph

TradeGraph answers export sales questions for consumer goods (cosmetics, food, supplements, lifestyle products): where to sell, which buyer types reply, how many follow-ups to send, what can block a market, and what the shelf price will be.

- For a product, start with `gtm_plan`. If the product's HS code is unclear, use `find_item` first.
- For one country, use `country_brief` or `buyer_targets`. For pricing, use `price_ladder`.
- Keep the sources and dates the tools return when you summarize an answer.
- The tools only read data. Without an account TradeGraph never spends money, and it never sends email for you.
